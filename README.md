太空中的「致命壓迫」：為什麼稀薄的大氣能燒毀流星？
在夏夜裡看見流星劃過天際，或是觀看太空船重返地球的紀錄片時，我們總會從新聞主播或地科老師口中聽到這句話：「這是物體與大氣層劇烈『摩擦生熱』的結果。」

這個解釋行之有年，卻常常讓具有物理直覺的人感到困惑。因為在地球表面上方 80 到 120 公里的高空（即流星與太空船開始發光的「熱層」與「中階層」），大氣極為稀薄。那裡的氣壓大約只有地表的百萬分之一，氣體分子的密度低到在實驗室裡都會被歸類為「高真空」。

試想，將手放在近乎真空的容器裡揮動，你連微風都感受不到。既然如此，一塊隕石在如此空曠、氣體鬼魅般稀薄的高空中，究竟是怎麼「摩擦」出一具足以熔化鋼鐵、激發白熾光芒的數千度火球？

答案是：我們都被「摩擦」這個詞誤導了。流星與太空船重返大氣層時的極端高溫，九成以上不是來自摩擦力，而是來自氣體的「絕熱壓縮」。
